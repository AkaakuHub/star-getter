# スターギャザー

固定プリセット「うなばら」「開花」のカードを組み合わせ、スターを回収するブラウザゲームです。読み込み直後に1:30のゲームが始まります。

キャラクターは「たいよう・くも・あめ」の3人です。衣装ごとの小物・配色・背景模様を持つカードで表現します。

## 開発

Node.js 24 LTSと[Vite+](https://viteplus.dev/)を使用します。

```sh
vp install
vp dev
```

```sh
vp check
vp test
vp run knip
vp build
```

TypeScript、Preact、Canvasで構成し、Oxlint・Oxfmtを`vp check`から実行します。lefthookはcommit時に検証を、push時にbuildを実行します。

## 内部計算のE2Eと操作記録

```sh
pnpm e2e
```

実ゲームと共通の初期化・カード効果・ゲーム時計を使い、DOMを使わずに1:30を進めます。両編成の準備と回収連鎖、手動回収と自動回収、連打速度の差、カードを使わない場合との比較を検証します。

カードは画面と同じ選択・使用の経路で実行します。判断時間0.45〜1秒、選択後の確定時間0.15〜0.35秒、共鳴一覧内の操作時間0.65〜1.4秒に、再現可能な乱数で揺らぎを付けます。これらは実測値ではなくテスト条件です。判断中もゲーム時計と自動回収を進め、一覧の停止中は操作に使った時間だけを進めます。カードの使用間隔はゲームと共通の判定に従います。ゲーム時刻と操作開始からの経過時間を分けて記録します。うなばらでは、95枚以上の形成と回収による引き直しを先に行い、増幅後に貝がらを使用する順序も検証します。初期手札はseed7・456・1234で確認します。

操作記録は`artifacts/e2e/`へJSONとMarkdownで保存します。失敗したテストの記録も残ります。同じケースの再実行では記録を更新します。

- JSONには各入力の時刻・tick・カード名・カードID・手札位置と、操作前後の得点・専用値・デッキ枚数・エナジー・スター上限・貝がらの蓄積増幅・空模様・手札ごとの累計回収数と発動状況を保存します。
- Markdownにはゲーム内のカード名で操作順を表示し、連続回収をまとめます。ファイル名の`library`はうなばら、`bloom`は開花を表します。

カード効果は`src/content/cards/`、計算処理は`src/domain/game/`、編成ごとの得点倍率とゲーム時間は`src/content/balance.ts`で管理します。画面とE2Eは共通の`src/app/createPresetGame.ts`を使います。

## うなばらの操作順

1. 準備中は自動回収をOFFにします。「乗船の準備」でエナジーを確保し、「潮の便り」の共鳴で追加カードを生成します。
2. 「港の待ち合わせ」「ヨット」「船出の合図」で95〜100枚へ近づけます。「浮き輪」で手札を引き直し、生成できるカードを探します。
3. 「舵」で空模様を晴れ100%にし、貝がらの使用や巻き込みでスター上限を50万以上へ広げます。
4. 手札の「浮き輪」が累計50万個の回収で引き直しを発動します。「貝がら」も累計50万個の回収でスターを生成します。どちらも発動時に95枚以上必要で、同じカードは引き直すと再発動できます。
5. 引き直しで「舵」を何度も引き、貝がらの増幅を積みます。その後、貝がらの使用や巻き込みでスター上限1000万を目指します。
6. 上限を広げた後は回収を繰り返します。95枚を下回ったら、次の回収より先に生成カードで補充します。連鎖が止まったら手札の引き直しやスター生成を使って再始動します。

回収中は左中央の自動停止をOFFにします。自動回収ONでは100個以上で0.3秒ごと、OFFではタップごとに回収します。記録のseedは固定ですが、通常の画面では初期手札が毎回変わるため、カードの出現順に合わせて操作します。
