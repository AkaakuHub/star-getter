# 固定プリセット

初期編成は各9枚で固定します。生成したカードには固有IDを割り当てます。まず元のカード同士の作用と計算を移植し、9999無量大数への数値調整は別の工程で行います。独自の1000万倍倍率は使用しません。

## 書架

CardSkills:2041523014、2031538014、8052501014、8053501014、8053502014、8053503014と、対応する能力9052501001・9053501001・9053502001・9053503001・3041523001・3031538001を参照しています。

- 招待状で共演カードを3枚、花咲くノートできらめき獲得カード8枚と補助カード各1枚を生成します。
- 共演は他の手札の消費量をまとめて支払い、使用前の手札を一斉に発動します。編成枚数に応じた減少量と、引いたときの消費量減少を計算します。
- 時を刻む合図は、このパート中の手札上限を3枚増やし、空模様を晴れ方向へ80変化させます。使用時にエナジーを5回復する独自効果は削除しました。
- 花のページは通常効果に加え、晴れ100%のときだけ追加効果を発動します。先に空模様を変えるか、先に使うかで、獲得数・上限・得点補正が変わります。
- 編成が80枚以上のとき、補助カードを引く能力と手札内の能力によって、花のページだけに+1001%の増幅が付きます。全てのカードを増幅する効果ではありません。晴れ方向の補正も適用します。
- 次の一幕は、使用時ではなく引いたときに編成枚数に応じてエナジーを回復します。引き直した場合にも発動します。
- 95枚以上で50万個を回収したときの追加獲得・引き直しも、使用と回収の別イベントとして処理します。
- 追加カードは使用後に除外します。効果は生成・ドロー・使用・手札内・回収のタイミングを区別します。

## 開花

補助アクションはCardSkills:2032530014、1032530014、3032530001、専用値の計算はgenesisSkill.tsとgenesisGauge.tsを参照しています。

- 空模様−100%で発動し、通常のエナジー・元気・熱気メーターを専用表示へ置き換えます。
- 専用値自体の最大は2,147,483,647です。回収スコアの上限とは別の値です。符号付き32bitのオーバーフローで負になった場合は0へ戻ります。
- 発動時の増幅量を専用値の増加係数に反映し、強い状態で再発動したときだけ係数を更新します。発動後の増幅は既存の係数へ遡って適用しません。
- エナジーの消費はなくなり、回復・獲得などのアクション効果を専用値へ変換します。通常の自動回復・自然減少は停止します。
- 発動時の通常メーター値を保持し、終了時に復元します。
- 準備した増幅と元気回復を先に使った場合と、開花後に使った場合の差をテストします。

上限と立ち回りの確認には[2026年5月の記事](https://note.com/muugenotekakuyo_/n/n3bcfc7ff3175)も参照しました。記事は発動時点の増幅、強い再発動の採用、約21.47億を超えた場合の0戻りを説明しています。
