# 固定プリセット

初期編成は各9枚で固定します。ライブ中に生成されたカードはそれぞれ固有のIDを持ちます。用語とカード名はラブギャザー独自のものにし、画像生成AIの画像は使用しません。

## 書架

百生吟子のCardSkills:2041523014、生成先8052501014、能力9052501001を参考にしています。

- 「書架の招待状」で共演カードを3枚生成します。
- 共演は他の手札の消費APの合計を基準に支払い、他の手札のスキルを一斉に使用します。デッキ枚数に応じて費用を減少させ、0枚・20枚・40枚・60枚・80枚・100枚の段階で5・5・10・10・20・50を加算して減少量を決めます。
- 共演は補助カード2種類を3枚ずつ追加し、使用後に除外します。単なる衣装違いではなく、他の手札のスキルを束ねて発動する使い切りのカードです。
- 「花咲くノート」で花のページ8枚、時を刻む合図1枚、次の一幕1枚を追加します。
- 花のページはハート、ハート上限、LOVE補正、ボルテージ、成長倍率を増加させます。
- 時を刻む合図は手札上限を増やし、次の一幕は手札をリセットして次の生成・循環へつなぎます。
- 追加カードは使用後に除外します。共演後は花のページ、花のページの後は次の一幕、といったドロー優先順を使用します。

## 開花

村野さやかのCardSkills:2032530014、1032530014、3032530001と、本家のゲージ変換処理を参考にしています。

- 開花中はAP・メンタル・ボルテージの増減を専用ゲージへ変換します。
- 「水色のステージ」はAP回復と条件付きの3回増幅を持ちます。手札内ではスキルハートを+300%し、手札上限を3枚減らします（画面上の最小手札は3枚です）。
- 「光のプリズム」などでスキルを増幅し、回収特性の再ドロー、専用ゲージ、LOVE成長を組み合わせます。

元データの全カードや全条件を復元する機能ではありません。30秒の固定デッキ用に、生成・一斉使用・除外・手札圧縮・AP回復・条件付き増幅の関係を取り入れています。
