# ライブの計算と配置

30秒間のミニゲームです。カードやプレイヤーを永続的に強化する機能はありません。効果増幅、開花プログレス、連続回収はライブごとに初期化します。

## 参照した実装とデータ

- llll-externalの`link-like-api-server/link-like-edit/src/domain/questLive/stageHudCanvasGeometry.ts`、`stageHudRectTransformHierarchy.ts`と保存済みHUDのRectTransformから、1080×1920基準の座標を確認しています。
- 下部左のメンタルは(-15,1216,176,264)、右のAPは(919,1216,176,264)、ボルテージは(600,1075,182,190)です。効果文は(120,1768,840,128)で固定します。
- `genesisSkill.ts`の初期ゲージ、資源変換と復元、`clientScore.ts`のアピール平均×120000とゲージの1.5乗を参考にしています。
- CardSkillsの2032530014（醒悟の地平から・さやか）はハート獲得、AP13回復、条件付きの3回・300%増幅です。1032530014はステージ中の50%効果増幅です。ラブギャザーでは既存の独自カードへ効果を割り当てています。

## ミニゲーム用の調整

- APは0.5秒ごとに1回復し、カード使用間隔は0.1秒です。
- 効果増幅は百分率の整数で保持し、次の増幅にも適用します。100→150→225のように増えます。
- 開花は資源を専用ゲージへ変換します。変換量はAPが√効果量、メンタルが2√効果量、ボルテージが√(50×効果量)を基本とし、開花発動時の強度を掛けます。資源は発動時の値を保持し、終了時に復元します。
- スキルのハート獲得数は効果増幅を適用した後に40個へ制限します。
- 手札の回収特性は一度だけ発動し、再ドローで復活します。
- 2秒以内に成功した連続回収には10の連続回収数乗の倍率を掛けます。空押し・期限切れ・溢れたハートの自動回収では連続回収数を増やしません。これはミニゲーム独自の倍率です。
- 得点、増幅、プログレス、倍率、平方根の計算はBigIntで処理します。平方根の端数は整数計算で切り捨てます。
- LOVEの上限は9999×10の68乗、つまり9999無量大数です。上限判定は表示ではなく得点計算へ適用します。
- 保存時も得点はJSONの数値リテラルとして書き込み、読込時はJSON.parseのsource情報からBigIntへ変換して全桁を保持します。

`tests/game/playBalance.test.ts`は初期編成・複数の乱数seedで30秒を進め、毎秒2回のカード使用・毎秒3回の回収・チャージ完了時のSP使用で上限へ到達すること、遅い操作では同じ得点にならないことを検証します。カード使用1回には選択と発動の2タップが必要です。
