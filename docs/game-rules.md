# ラブギャザー

読み込み直後に30秒のライブを開始します。楽曲は潮風シグナルの1曲、固定プリセットは「書架」「開花」の2つです。自由編成・楽曲選択・育成・アルファベット評価はありません。

## 操作

- カードを選択し、もう一度押すと使用します。
- 使用カードは0.25秒で手札の位置から中央へ移動し、傾きを戻します。発動時刻の0.75秒から0.25秒でフェードします。本家の移動時間・発動遅延・フェード時間を参照し、Web Animations APIで描画します。
- 黒い効果説明はポインター入力を透過し、重なった手札を押すことができます。
- 一時停止は左側中央、手札確認はHUDの左下、設定は右上です。
- 手札確認モーダルからカードを選ぶと、一時停止したまま効果を確認できます。
- 右上の設定でプリセット、ハート表示数、音声を変更します。プリセット選択でそのプリセットのライブを即座に開始します。

## 得点

本家のアピール正規化、回収数×ボルテージによるハートランク、LOVE補正、開花ゲージを基礎計算に使用します。そこへライブ中の成長倍率をBigIntで乗算し、9999無量大数を目標にします。成長カードは現在の倍率を1000万倍にし、再使用するたび複利で増えます。育成や次のライブへの倍率の持ち越しはありません。

結果にはスコアと目標を表示します。X共有はスコア、プリセット名、ハッシュタグ「ラブギャザー」、location.hrefの現在URLをTwitterの投稿画面へ渡します。プリセットはURLのrouteパラメーターに保持します。

## 描画と時間

ハートの乱数範囲、飛び出し、落下、点滅、回収移動は本家から移植した計算を使用します。Canvas1枚に、準備済みのLucideアイコンを再利用して描画します。表示上限は10〜100個を10個刻みで選択でき、初期値は100個です。表示しない分は個数と寿命で保持し、得点を変えません。

描画fpsや画素密度には独自の上限を設けません。デバイスのrequestAnimationFrameとdevicePixelRatioに従い、一時停止・終了中は連続描画を止めます。

ライブ時計は音声の許可待ちに依存せず進みます。音声再生を許可するブラウザーでは読み込み時に再生を試み、制限がある場合は最初の操作で現在の曲位置へ同期します。一時停止・再開・外部音声中断でも停止時間をゲームへ加えません。

- routes.test.ts:2つの固定プリセット、共演の生成・一斉使用・除外、全カードの所有状態、両ルートの目標到達。
- cardMotion.test.ts:移動先、回転、発動後のフェード。
- heartDisplay.test.ts:表示上限を変えた場合の得点・循環の一致。
- shareScore.test.ts:スコア、ハッシュタグ、現在URL、プリセットの共有。
- liveClock.test.ts / gameController.test.ts:開始・一時停止・再開・終了。
