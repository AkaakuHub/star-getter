# スターギャザー

読み込み直後に30秒の演奏を開始します。楽曲は潮風シグナルの1曲、固定プリセットは書架・開花の2つです。育成・自由編成・楽曲選択・アルファベット評価はありません。

## 操作

- カードを選択し、もう一度押すと使用します。使用できないカードも性能を確認できます。
- 左中央で、使用可能なカードが1枚でもあれば自動停止する設定と、100個で自動回収する設定を切り替えます。自動回収は100個以上が0.3秒続くと発動します。
- 手札・山札の確認中は演奏を停止します。一覧から性能画面を開いてもカードは使用せず、閉じると元の一覧へ戻ります。
- 音量は左上のアイコン、プリセットと描画数は右上の設定から変更します。描画数は10〜100個、初期値は100個です。論理上の個数と得点は描画数に依存しません。
- ダブルタップ拡大・文字選択・長押しメニューを抑止します。

## 準備と回収

単体カードに独自の巨大倍率を付けず、空模様・効果増幅・編成枚数・対象限定の増幅・獲得上限を組み合わせます。書架では空模様と編成を準備して生成カードを使い、開花では発動前の増幅を専用ゲージの増加係数に反映します。詳細はroutes.mdに記載します。

開花は空模様−100%で発動します。通常の3メーターが専用メーターに変わり、その値自体で2³¹−1を目指します。上限を超えると0へ戻るため、準備後は専用値を増やすカードの使用を止めて回収へ移れます。時間経過だけでは専用値は変動しません。

## 得点

元コードのパワー正規化、熱気段階と回収数による倍率、追加補正、専用値の1.5乗を使用します。1回の回収上限は100個以下で2³¹−1、100個を超えるとStageScoreMultiplierSettingsの10区分の値で増加します。きらめき上限は1000万です。専用ゲージの最大値と回収スコアの最大値を混同しません。

9999無量大数に届かせる数値調整は、この移植工程では行いません。表示機能は無量大数まで保持します。STARは京までのゼロ埋め・3桁のカンマ区切りで始まり、4桁ごとの小さな単位と、増加時の最大3行の表示を使用します。

結果から、得点・プリセット名・ハッシュタグ「スターギャザー」・location.hrefのURLをXへ共有できます。

## 描画と演出

きらめきの描画は、Lucideのアイコンを準備してCanvasへ再利用します。requestAnimationFrameとdevicePixelRatioに従い、独自のfps上限は設けません。停止中は連続描画も止めます。

使用カードは0.25秒で中央へ移動し、0.75秒後から0.25秒でフェードします。黒い効果説明は入力を透過します。空模様のグラフは−100〜100の段差状の線、区間境界、現在位置、山場の帯を表示します。

音声許可待ちでも演奏時計は進み、ブラウザーの制限がある場合は最初の操作で音声を現在位置へ同期します。
